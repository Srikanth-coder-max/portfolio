Agentic AI + VoiceMarch 2026

ContextualVoice — AI Agent with RAG, Memory & Tool Orchestration

Most AI assistants are stateless and siloed. ContextualVoice solves context-loss by combining three-tier persistent memory, local document RAG, live web search, and voice I/O in a single orchestrated pipeline.

Architecture

Key Engineering Decisions

Three-tier memory — JSON short-term (10 turns), user profile, and Chroma vector archive for semantic cross-session recall

Provider-agnostic LLM — single env var switches Groq, Gemini, or Ollama without touching application code

Tool registry pattern — tools registered independently, brain fully decoupled from execution logic

Dual interface design — CLI (main.py) for terminal, Streamlit (app.py) for browser; FastAPI backend for optional API serving

Highlights

3 live tool integrations: DuckDuckGo search, Weather API, Todoist NLP task management

Chroma vector archive makes conversation history semantically searchable across sessions

Live Streamlit deployment — browser-accessible with full voice mode and document upload

What it solves: stateless chatbots lose context; hallucinate on private docs; can't act on real-world tasks. This solves all three in one system.

Cloud Automation · AWSApril 2026

Intelligent Cloud Deployment Orchestration System

A bad deployment to EC2 used to mean manual triage. This event-driven system watches health via CloudWatch, detects failures instantly via EventBridge, and triggers Lambda to roll back automatically — recovery in under 2 minutes, zero human intervention.

Architecture

Key Decisions

Event-driven, not polling — CloudWatch alarm state change triggers EventBridge rule instantly; no cron, no manual check

IAM least-privilege — CodeDeploy, Lambda, EC2 roles separated with explicit scoped trust policies

AppSpec lifecycle hooks — stop.sh → install.sh → start.sh makes deployments fully observable
